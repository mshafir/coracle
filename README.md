# Coracle

A fast, lightweight, local-first web browser for macOS and Linux, built on the
system WebKit engine (WKWebView on macOS, WebKitGTK on Linux).

**Status: planning.** There is no code yet. Decisions are being worked through
in the open on this repo's [issue tracker](../../issues).

## What it aims to be

- A sidebar browser: tabs on the left, organised into spaces, folders and groups.
- Profiles, so each space can use its own cookies and logins.
- Configurable expiry for tabs you haven't pinned.
- Everything you arrange (settings, spaces, pinned tabs, colors) stored as plain
  files in a folder you can sync however you like. No accounts, no backend.
- Built-in AI page interaction that runs on your own machine with your own
  subscription, starting with Claude.
